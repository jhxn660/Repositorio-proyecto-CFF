# Proyecto_Corralejo_Fast_Food

---

Objetivo Desarrollar un sistema de información web para el restaurante Corralejo Fast Food, que permita centralizar y optimizar los procesos operativos relacionados con la administración integral del menú, el control de insumos, la organización y trazabilidad de los pedidos, el registro automatizado de ventas, el control de usuarios y la gestión estructurada de PQRS. Con el fin de garantizar la integridad de la información, facilitar la visualización de indicadores de negocio para la toma de decisiones estratégicas y mejorar significativamente la eficiencia operativa y el servicio al cliente dentro del establecimiento.
